Advanced Web Design Development

  • Overview
  • Assessments
  • Course Syllabus

This course exposes students to essential concepts of the World Wide Web that enable modern web applications for managing online information. It focuses on both client-side and server-side scripting to develop secure, database-driven applications for efficient information storage, retrieval, and interactive access.

Students are also introduced to web application development using Integrated Development Environments (IDE), along with the application of standard metadata elements to support structured information management, retrieval, and dissemination.

Key Learning Areas
  • Client-side & server-side scripting
  • Database-driven web application development
  • Secure data storage and retrieval techniques
  • Use of IDE tools for development workflow
  • Metadata standards for information organization
Web Development Database

This course assessment evaluates students through a combination of individual and group work. Each component contributes to the final grade, focusing on continuous learning, practical application, teamwork, and final evaluation.

Continuous Assessment (70%)

Evaluates ongoing performance throughout the semester including participation, quizzes, in-class activities, assignments, and presentations. This assessment includes both individual and group tasks.

1. Individual Assessment (20%)
  • Students must apply the theories, techniques, and tools learned in lectures to build a small-scale but professional web application prototype.
  • Each student must design and develop a web application interface using any suitable theme
2. Group Assessment (50%)
  • Each student must design and develop a web application interface and has a functional database using any suitable theme
  • Database-driven web application development
3. Final Test (30%)
  • Written test assessing overall understanding of the course.
Final Examination (30%)

Written or practical examination assessing overall understanding of the course.

Course Syllabus

This syllabus outlines the main topics covered throughout the course, starting from foundational web concepts to advanced web application development, database integration, and open-source frameworks.

1. Internet, World Wide Web and Applications
  • Keeping up-to-date with IT
  • Content Management Systems (CMS)
  • Web Basics
  • Web 2.0, Web 3.0 and Future Web
2. Browsers and Web Servers Fundamentals
  • HTTP Transaction
  • Web Browsers
  • Multitier Application Architecture
  • Accessing Web Servers
  • Web Server Packages (WAMP, LAMP, MAMP, XAMPP)
3. Markup and Style Sheet Language (XHTML & CSS)
  • Introduction to XHTML & CSS
  • Elements and Attributes
  • CSS Selectors and Properties
  • Inline, Internal and External Stylesheets
4. XML and Metadata Concepts
  • XML Basics and Data Structuring
  • XML Namespaces and DTD
  • XSL (eXtensible Stylesheet Language)
  • Metadata Standards (DCMI, METS, MODS, RDF)
5. Client-Side Scripting
  • Variables, Operators, Functions
  • Control Structures and Arrays
  • Objects and Events
  • Cookies
6. Server-Side Scripting
  • Data Types, Variables, and Constants
  • Conditionals and Loops
  • Forms and User Input
  • Files, Sessions, and Cookies
  • Object-Oriented Concepts
7. Web Database Design and Content Management
  • Database Connectivity
  • SQL Query Execution
  • Data Retrieval, Update, and Deletion
  • Database Functions
8. Secure Database-Driven Web Application
  • System Architecture Overview
  • User Interface Design (Layout, Navigation, UI/UX)
  • Security, Sessions, and Cookies
  • Data Entry, Search, Edit, and Delete Functions
  • FAQs, Help, and Contact Modules
9. Open Source Information Systems
  • CMS Platforms (Mambo, Joomla)
  • Frameworks (Laravel, CodeIgniter, CakePHP)
Level: Intermediate Credit: 3 Hours
