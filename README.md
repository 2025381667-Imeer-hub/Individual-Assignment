# Student Portal Website: EduTrack Website

## Project Description
This project is a Student Portal Website developed as an individual assignment. The Edutrack website is designed to help students manage their academic activities through a modern and responsive interface. It includes features such as a dashboard, task management, grades page, courses page, and profile page.

The system is built using front-end web technologies and focuses on user-friendly navigation, responsive layouts, and clean UI/UX design.

---

## Features Included

- **Login Feature**  
  Allows users to securely log in using their credentials to access the system.

- **Logout Feature**  
  Allows users to securely log out of the website.

- **Student Dashboard**  
  Provides an overview of student performance, upcoming classes, pending assignments, and total credits.

- **Task / Assignment Management**  
  Lets students view, track, and manage their assignments and deadlines.

- **Grades Page**  
  Displays previous semester results and academic performance records.

- **Profile Section**  
  Shows and manages student personal information, recent activity, and achievements.

- **Course Page**  
  Displays all registered courses.

- **Specific Course Page**  
  Limited to IMS566 and IML512 in this project. Provides access to course information such as course overview, assessments, syllabus, announcements, and upcoming classes. Also includes access to course materials, assignment submission, class schedule, and group member information.

- **Notes View**  
  Limited to IMS566 and IML512 in this project. Allows students to access lecture notes (only Chapter 1 for each course) and assignment guideline view.

- **Schedule Page**  
  Shows class timetable and weekly academic schedule.

- **Attendance Page**  
  Limited to IMS566 and IML512 in this project. Displays attendance records for IMS566 (18/5/2026) and IML512 (22/5/2026) only.

- **Assignment Submission Page**  
  Allows students to view and submit assignments for IMS566 and IML512.

- **Dark Mode**  
  Enables a dark theme for better visual comfort and improved user experience.

- **Notification System**  
  Shows alerts such as deadlines, updates, and announcements.
